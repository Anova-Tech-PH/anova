# UX Evaluation Report: Phase B — Logistics, Sponsors, Website Builder

**Date:** 2026-08-12
**Tested by:** Claude (Playwright MCP)
**Pages tested:**
- `/events/{id}/logistics` (organizer)
- `/events/{id}/sponsors` (organizer)
- `/events/{id}/sponsors/{sponsorId}` (organizer detail)
- `/events/{id}/website` (organizer)
- `/test-org-eq12/sample-conference-2026/logistics` (public)
- `/test-org-eq12/sample-conference-2026/sponsors` (public)
- `/test-org-eq12/sample-conference-2026/website` (public)

## Summary

All Phase B pages load correctly with no console errors. Core CRUD flows work (tier creation, sponsor creation). Empty states are present and helpful. The website builder has a well-structured section editor with theme picker. Public pages render appropriate content or empty states.

## Critical Issues (fix before release)

| # | Heuristic | Issue | Recommendation | Severity |
|---|-----------|-------|----------------|----------|
| 1 | Error Prevention | Q&A page returns 500 — `getModerationQueue` tries to join `session_questions` with `user_id` which doesn't exist as a relationship | Fix the join in `qa/queries.ts` `getModerationQueue` — use `.select("*")` or the correct join syntax. **Pre-existing bug, not Phase B.** | Critical |

## Major Issues (fix soon)

| # | Heuristic | Issue | Recommendation | Severity |
|---|-----------|-------|----------------|----------|
| 1 | Visibility of System Status | Logistics "Save Changes" button has no loading state — user gets no feedback while saving | Add `loading` prop or `isPending` state to the Save button, show "Saving..." text | Major |
| 2 | Post-Action Navigation | Sponsor detail page has no edit capability inline — user must go back to list, find sponsor, and use hover actions to edit | Add an "Edit" button on the sponsor detail page header | Major |
| 3 | Information Architecture | Website builder "Preview" link goes to `/preview-website/{id}` but this route likely doesn't exist as a public page (public route is `/{org}/{event}/website`) | Either create the preview route or link to the actual public website URL | Major |

## Minor Issues (nice to have)

| # | Heuristic | Issue | Recommendation | Severity |
|---|-----------|-------|----------------|----------|
| 1 | Consistency | Tier inline form buttons (Check/X icons) have no labels or tooltips — unclear which is save vs cancel | Add `title="Save"` and `title="Cancel"` to the icon buttons | Minor |
| 2 | Empty States | Public logistics page empty state ("No logistics information has been shared yet") could include a link back to the event page | Add "Return to event" link below the empty state message | Minor |
| 3 | Visibility of System Status | Sponsor form submit button is labeled "Add Sponsor" even while saving — no loading indicator text | The `loading` prop is passed but the button text should show "Saving..." (already coded but verify it triggers) | Minor |
| 4 | Information Architecture | Website builder section list buttons (up/down arrows, show/hide) are icon-only with no labels | Add `title` attributes: "Move up", "Move down", "Show/Hide section" | Minor |
| 5 | Consistency | Sponsor detail analytics cards show visit/lead counts in quotes ("0") — should be plain numbers | Check if the rendering wraps numbers in quotes unintentionally | Minor |

## What's Working Well

- **Tier CRUD**: Inline add/edit with Enter key support is efficient and intuitive
- **Sponsor form**: Clean modal with all fields, proper required field marking, disabled submit until valid
- **Sponsor detail page**: Well-organized tabbed layout (Details, Documents, Coupons, Leads) with analytics summary
- **Website builder**: Comprehensive section management with reorder, show/hide, theme customization, and custom CSS
- **Public sponsors page**: Sponsors grouped by tier with clear visual hierarchy
- **Public website**: Appropriate "not available" message when website is disabled
- **Empty states**: Present on all pages (tiers, sponsors, logistics) with helpful guidance text
- **Navigation**: All sidebar links and public nav items correctly added and linking to proper routes
- **Back navigation**: Sponsor detail has "Back to Sponsors" link for easy return

## Recommended Next Steps

1. Fix Q&A `getModerationQueue` join error (critical, pre-existing)
2. Add loading state to Logistics save button
3. Add edit button on sponsor detail page
4. Fix website preview link to use correct route
5. Add tooltips to icon-only buttons (tier form, website sections)
