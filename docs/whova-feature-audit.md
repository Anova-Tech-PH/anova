## TOP PRIORITY FEATURES TO BUILD (Recommended Order)

### Phase 1: Core Event Experience
1. **Announcements / Push Notifications** - Send targeted messages to all or segmented attendees (49 sent for GHS!)
2. **Session Feedback** - Attendees rate and review sessions
3. **Live Polling** - Real-time polls during sessions
4. **Session RSVP / Capacity** - Per-session registration with capacity limits

### Phase 2: Attendee Management
5. **Name Badges** - Generate printable badges with QR codes
6. **Attendee Categories & Segments** - Group attendees for targeted communication
7. **Kiosk Check-in** - Self-service check-in kiosk mode
8. **Certificates** - Auto-generate attendance certificates

### Phase 3: Marketing & Growth
9. **Embeddable Widgets** - Agenda/speaker/registration widgets for external sites
10. **Email Campaigns** - Built-in email marketing for ticket sales
11. **Abandoned Registration Recovery** - Re-engage partial sign-ups

### Phase 4: Advanced Engagement
12. **Gamification** - Points, badges, leaderboard to drive engagement
13. **1-1 Meeting Scheduler** - Attendee networking tool
14. **Event Photos** - Shared photo wall with moderation
15. **Floormap** - Interactive venue maps
